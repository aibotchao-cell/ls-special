# ⚽ LS 特輯 — 街頭足球大亂鬥

用 Three.js 寫的**獨立特輯**（跟主遊戲分開的檔案與連結，主遊戲在 `../voxel-fps`）。

## 🎮 怎麼玩
| 平台 | 操作 |
|---|---|
| 🖥 電腦 | WASD 移動 · 滑鼠轉視角 · **左鍵 = 射門** · **1 / 2 / 3 = 換球種** · 空白鍵跳 · Esc 暫停 |
| 📱 iPad | 左半螢幕拖曳 = 移動 · 右半螢幕拖曳 = 轉視角 · 右下「射門」按鈕 · 右上角切換球種 |

**玩法**：一波一波的對手從球場各處衝向你（撞到你會扣血）。用球把他們**打到沒血 → 直接飛出場外**。
清空一波 → 休息 2 秒 → 下一波（人數慢慢變多、變硬）。血量歸零會原地起身 + 5 秒無敵。

## 🏟 場景
- **五人制足球場**：綠茵草皮（深淺條紋）、白線（邊線／中線／中圈／禁區／球門區）、中點
- **兩端球門**：白色門柱＋橫樑＋球門網（球會打進網子裡）
- **四周只有鐵網**：菱形網目的鐵網圍住整個球場，球撞到會**反彈**，對手飛出去會直接飛越鐵網
- 場外是柏油地、四角有角旗；明亮的藍天陽光

## ⚽ 三種足球（右下角切換）
| 球種 | 特性 |
|---|---|
| ⚽ **一般直球** | 最快最直（42 傷、冷卻 0.30 秒），最好控制 |
| 🔥 **火焰球** | 命中會讓對手**著火 3.2 秒持續扣血**，還會**小爆炸**波及附近的人（30＋爆炸 20） |
| 🌀 **旋風旋球** | 飛行時會**轉彎**、可以**穿透**多個對手，被打到的會被**高高擊飛**（36 傷、擊飛力最強） |

## 🦖 對手（8 種頭）
鱷魚（長嘴＋尖牙）· 恐龍（頭冠）· 漢堡（分層＋芝麻）· 金剛（黑毛＋眉骨）· 小牛（牛角＋粉紅鼻）·
紅鷹（黃喙＋頭冠）· 紅豹（尖耳＋鬍鬚）· **爆炸頭紅衣教練**（紅色球衣＋黑色爆炸頭＋哨子）

每種頭的體型／血量／速度都不一樣（金剛最硬、紅豹最快、教練血最多）。

## 🧩 檔案結構
```
ls-special/
  index.html         畫面與 HUD（球種列、波次、擊飛數）
  styles.css         介面樣式（沿用主遊戲，加上球種卡片）
  serve.py           本機伺服器（埠 8100，含存檔 API）
  release.py         發版工具（差異檔 + CHANGELOG + 版本號 + git tag）
  js/
    main.js          主迴圈、HUD、波次、射門
    world.js         球場產生器（草皮／白線／球門／鐵網）＋ 方塊網格化
    enemies.js       8 種頭像、AI（衝撞）、被擊飛出場
    balls.js         三種足球的物理（彈跳、轉彎、爆炸、穿透）
    player.js        移動／重力／碰撞（與主遊戲相同操作）
    controls.js      電腦＋觸控輸入（與主遊戲相同操作）
    textures.js      程序化材質圖集（含鐵網、球門網）
    version.js       版本號（由 release.py 自動更新）
  vendor/three.module.js
```

## 📝 版本紀錄
每個版本都有 `CHANGELOG.md` 條目與 `versions/vX.Y.diff` 差異檔，發版用：
```
python release.py 1.1 "說明"        # 產生差異檔 + 更新 CHANGELOG + 版本號 + commit + tag
```
